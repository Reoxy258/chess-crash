# 十字连爆 · Chess Crash

一颗点数，一排连锁。四点分裂、十字冲击的休闲解谜 H5 小游戏：80 关战役（四类特殊形状棋自第三章登场）+ 无限挑战 + 每日挑战，合理分配手中的点数，清空整块棋盘。

## 游玩

在线地址：https://reoxy258.github.io/chess-crash/

- 点击棋子给它 **+1 点**，手牌点数有限；
- 棋子满 **4 点**即分裂：本身消失，按棋子形状给波及范围内的棋子各 +1；
- 被 +1 后到 4 的棋子连锁分裂，一波接一波，看冲击波扫过全场；
- **清空棋盘**即获胜；手牌耗尽仍未清空则失败。

五种波及形状：

| 棋子 | 外观 | 分裂时波及 |
|------|------|-----------|
| 普通 | 圆点 | 同一横行 + 纵列（十字） |
| 横线 ▬ | 横胶囊 | 同一横行 |
| 竖线 ▮ | 竖胶囊 | 同一纵列 |
| 三角 ▲▼◀▶ | 朝向三角 | 整行/整列 + 沿角朝方向的半臂（T 字形） |
| 方框 ■ | 圆角方块 | 周围一圈 8 邻域 |

特殊棋子从第三章（第 11 关）开始登场，逐章引入：直线 → 三角 → 方框 → 全形状混战；无限挑战与每日挑战在高难度档也会混入。一次点击连消多颗会触发激励音（波内多消喝彩、结算上行琶音，消得越多音越长）。

休闲设计：提示免费、不扣星；悔棋随便用；失败可以看最优解演示，关卡布局固定，背板再战；每关一分钟，输了秒重开。连锁动画中点一下棋盘（或按空格）即可加速；右上角一键静音；三星过关撒彩带。

## 挑战模式

战役之外还有两种跑分玩法，与「背板重试」的战役互补：

- **♾ 无限挑战**：一关接一关，棋盘从 6×6 逐步放大到 9×9、手牌从 +2 收紧到恰好等于最优解；失败即结算，结算面板显示通过关数、累计投点、最大连锁与最佳纪录（破纪录有「新纪录！」标记）。
- **📅 每日挑战**：由日期种子生成的确定性关卡，同一天全站同款；难度按「年内第几天 % 7」轮换 7 档；可无限重试，星数取当天最佳。

两种模式的关卡都在运行时由 `challenge.js` 即时生成并经 solver 验证（最优解深度 === par），无限挑战每轮换种子，每日挑战当天缓存到本地（`cc-daily-v1`）。

## 战役结构

16 章 × 5 关，每章一个手法主题：

| 章 | 主题 | 学什么 |
|---|------|--------|
| 一 | 认识分裂 | 单点引爆、连锁全清 |
| 二 | 引爆顺序 | 先送点再收割，顺序就是一切 |
| 三 | 直线初现 | 横线只扫整行、竖线只灌整列 |
| 四 | 手紧点数 | 手牌刚好等于最优解，错一步即败 |
| 五 | 三角锋芒 | 三角看朝向：整行/列 + 角朝方向的半臂 |
| 六 | 队形与对齐 | 十字路口、一字长蛇、锋线走廊 |
| 七 | 空降播种 | 解锁「播种」：点空格花 1 点放新棋子，接住冲击波 |
| 八 | 方阵内爆 | 方框只轰周围一圈 8 邻域 |
| 九 | 形状协奏 | 四类形状同场协奏 |
| 十 | 手紧进阶 | 零容错遇上全形状 |
| 十一 | 大盘风暴 | 8×8 大军团作战 |
| 十二 | 播种大师 | 大盘播种，波网空洞里下子 |
| 十三 | 混沌终局 | 9×9 混战 |
| 十四 | 钢索行走 | 深水零容错 |
| 十五 | 万形齐发 | 特殊形状密度拉满 |
| 终章 | 万象归一 | 八十关的最后一爆 |

星级按投点数计算：≤ 最优 3 星，≤ 最优 + 1 得 2 星，通关 1 星。通关前一关解锁下一关；进度保存在浏览器本地。

## 本地开发

不需要安装第三方依赖，使用 Node.js 20 或更高版本：

    npm start          # 预览：http://127.0.0.1:4173/
    npm test           # 52 项自动测试（引擎/求解器/关卡/挑战生成）
    npm run levels     # 重新生成并验证 80 个关卡（固定种子，可复现）
    npm run build:offline  # 在项目父目录生成 chess-crash.html，双击即玩

可用环境变量 `PORT` 指定其他端口。

## 实现

- `engine.js`：不可变状态、确定性规则、同步波次连锁、五类波及形状（十字/横线/竖线/三角 T/方框，`cells[i] = (kind << 5) | points` 编码）、逐波 trace（含冲击波距离与波源形状，供演出）。
- `solver.js`：迭代加深搜索（置换表 + 形状感知下界 + 启发排序），求最小投点数；关卡验证与运行时提示共用。
- `levels.js`：80 关固定数据，由 `tools/generate-levels.cjs` 生成并经 solver 逐关验证（最优解深度 === par；第七、十二章最浅解必含播种步；混形关每族形状保底一颗）。
- `challenge.js`：无限挑战与每日挑战的运行时生成器——mulberry32 确定性随机 + 难度曲线配方（6 起横竖线、10 起三角、14 起方框，随难度混入）+ solver 验证 + 未中扰动种子轮换（浏览器全局 `CC_CHALLENGE` / Node require 双导出）。
- `app.js`：交互、按距离延迟的形状波及光点（横线琥珀/竖线蓝/三角紫/方框绿）、爆裂粒子、震屏、连锁徽章、WebAudio 合成音效（连锁波次音高阶梯 + 多消激励音，可静音）、动画点击加速、三星彩带、教程、提示、答案回放、进度存档、三种模式的流程分流（战役/无限挑战/每日）。
- `style.css` / `index.html`：响应式界面；点数即色温（1 蓝 → 2 琥珀 → 3 赤红预警），形状即轮廓（圆点/胶囊/三角/圆角方），320px 起可玩。
- `tests/`：引擎规则回归（含五类形状波及范围）、求解器回归、80 关全量复算。
- `tools/`：关卡生成器、离线构建、冒烟脚本。

规则要点（实现与测试均以此为基准）：

- 稳定棋盘每格 1–3 点；每回合给一颗棋子 +1（第七章起可花 1 点在空格播种 1 点新棋子）；
- 同一波次内达到 4 的棋子同时分裂：分裂者先行移除、互不加成，存活者可叠吃多道波，超过 4 点同样整颗消失；
- 棋子数单调递减、空格不自动生棋，连锁必然终止；
- 无道具、无随机：同一关卡永远同一布局。

## 关卡再生成

    npm run levels -- 20261023

固定种子的确定性生成：随机棋盘（按章节配方）→ solver 求最优 → 精确匹配目标 par 与章节约束 → 收录写入 `levels.js`。换种子即得到一批新关卡，旧 `levels.js` 会被覆盖（玩家进度按关卡 id 存储，换关卡需注意）。
