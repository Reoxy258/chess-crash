# 十字连爆 · Chess Crash

一颗点数，一排连锁。四点分裂、十字冲击的休闲解谜 H5 小游戏：30 关战役，合理分配手中的点数，清空整块棋盘。

## 游玩

在线地址：https://reoxy258.github.io/chess-crash/

- 点击棋子给它 **+1 点**，手牌点数有限；
- 棋子满 **4 点**即分裂：本身消失，**同一横行和纵列**上的所有棋子各 +1；
- 被 +1 后到 4 的棋子连锁分裂，一波接一波，看冲击波扫过全场；
- **清空棋盘**即获胜；手牌耗尽仍未清空则失败。

休闲设计：提示免费、不扣星；悔棋随便用；失败可以看最优解演示，关卡布局固定，背板再战；每关一分钟，输了秒重开。

## 战役结构

6 章 × 5 关，每章一个手法主题：

| 章 | 主题 | 学什么 |
|---|------|--------|
| 一 | 认识分裂 | 单点引爆、连锁全清 |
| 二 | 引爆顺序 | 先送点再收割，顺序就是一切 |
| 三 | 手紧点数 | 手牌刚好等于最优解，错一步即败 |
| 四 | 队形与对齐 | 十字路口、一字长蛇、边角的弱点 |
| 五 | 空降播种 | 解锁「播种」：点空格花 1 点放新棋子，接住冲击波 |
| 终章 | 综合爆发 | 大棋盘混合手法，30 关的最后一爆 |

星级按投点数计算：≤ 最优 3 星，≤ 最优 + 1 得 2 星，通关 1 星。通关前一关解锁下一关；进度保存在浏览器本地。

## 本地开发

不需要安装第三方依赖，使用 Node.js 20 或更高版本：

    npm start          # 预览：http://127.0.0.1:4173/
    npm test           # 31 项自动测试（引擎/求解器/关卡）
    npm run levels     # 重新生成并验证 30 个关卡（固定种子，可复现）
    npm run build:offline  # 在项目父目录生成 chess-crash.html，双击即玩

可用环境变量 `PORT` 指定其他端口。

## 实现

- `engine.js`：不可变状态、确定性规则、同步波次连锁、逐波 trace（含冲击波距离，供演出）。
- `solver.js`：迭代加深搜索（置换表 + 乐观下界 + 启发排序），求最小投点数；关卡验证与运行时提示共用。
- `levels.js`：30 关固定数据，由 `tools/generate-levels.cjs` 生成并经 solver 逐关验证（最优解深度 === par；第五章最浅解必含播种步）。
- `app.js`：交互、按距离延迟的十字冲击光点、爆裂粒子、震屏、连锁徽章、WebAudio 合成音效（连锁波次音高阶梯）、教程、提示、答案回放、进度存档。
- `style.css` / `index.html`：响应式界面；点数即色温（1 蓝 → 2 琥珀 → 3 赤红预警），320px 起可玩。
- `tests/`：引擎规则回归、求解器回归、30 关全量复算。
- `tools/`：关卡生成器、离线构建、冒烟脚本。

规则要点（实现与测试均以此为基准）：

- 稳定棋盘每格 1–3 点；每回合给一颗棋子 +1（第五章起可花 1 点在空格播种 1 点新棋子）；
- 同一波次内达到 4 的棋子同时分裂：分裂者先行移除、互不加成，存活者可叠吃多道波，超过 4 点同样整颗消失；
- 棋子数单调递减、空格不自动生棋，连锁必然终止；
- 无道具、无随机：同一关卡永远同一布局。

## 关卡再生成

    npm run levels -- 20261023

固定种子的确定性生成：随机棋盘（按章节配方）→ solver 求最优 → 精确匹配目标 par 与章节约束 → 收录写入 `levels.js`。换种子即得到一批新关卡，旧 `levels.js` 会被覆盖（玩家进度按关卡 id 存储，换关卡需注意）。
